Este repositório apresenta uma coleção de exercícios desenvolvidos em JavaScript com foco no uso de estruturas de repetição, especialmente o loop *while*. O objetivo principal é reforçar a lógica de programação por meio de situações práticas que exigem validação de dados e repetição de instruções até que determinadas condições sejam atendidas.

No primeiro exercício, o programa solicita que o usuário digite um número positivo. Caso o valor informado seja negativo, o sistema continua pedindo novos valores até que uma entrada válida seja fornecida. Esse exercício demonstra o uso do *while* para garantir que uma condição seja satisfeita antes de prosseguir.

O segundo exercício permite que o usuário insira notas de forma contínua. O programa só é encerrado quando um número negativo é digitado. Ao final, é calculada e exibida a média das notas informadas. Aqui, o *while* é utilizado para controlar a repetição e acumular valores até que a condição de parada seja atingida.

No terceiro exercício, o usuário informa valores de compras sucessivamente. Quando o valor zero é digitado, o programa interrompe a entrada de dados e exibe o total acumulado. Esse exemplo reforça o uso do *while* em situações de soma contínua com condição de parada definida pelo usuário.

O quarto exercício solicita o primeiro nome e o sobrenome separadamente. Caso algum dos campos seja deixado em branco, o programa solicita novamente a informação até que ambos sejam preenchidos corretamente. Esse caso demonstra o uso do *while* na validação de entradas de texto.

O quinto exercício simula um sistema simples de saque bancário. O programa possui um saldo inicial armazenado em uma variável. O usuário informa o valor que deseja sacar, e o sistema verifica se há saldo suficiente. Caso não haja, ele solicita um novo valor. O processo se repete até que o saldo seja zerado ou negativo. Esse exercício combina validação com atualização de estado dentro de um loop *while*.

Todos os programas foram desenvolvidos para execução no ambiente Node.js, utilizando entrada de dados pelo terminal. Para executá-los, é necessário instalar a dependência prompt-sync e rodar os arquivos com o comando node.

Este projeto foi desenvolvido por Livia Crema como parte dos estudos iniciais em programação, com ênfase na compreensão e aplicação de estruturas de repetição do tipo *while*.
